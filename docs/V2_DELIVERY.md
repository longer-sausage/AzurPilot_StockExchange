# v2 重构交付与部署记录

核验日期：2026-11-01（上海时间）。本记录只包含非敏感信息，不保存真实用户身份、密钥、密码或服务器地址。

## 已实现

- 独立公开站点 `https://stock.azurpilot.com`，管理入口 `/console`；行情首页不强制登录，交易及管理员登录均有“记住我”。首次开户或重置后强制设置新密码。
- 交易账户由官方 QQ 机器人身份 `appid:openid` 领取一次性注册密钥，在网页自选用户名完成开户。官方接口无法取得数字 QQ 号，采用用户已确认的唯一身份方案。
- 实例股票由 AzurPilot 独立注册；股票用户名、私密绑定码、机器人永久一对一绑定、绑定后跳转交易站。群号与链接按要求配置。
- 官方 QQ 插件覆盖帮助、注册、二次确认重置、持仓、按编号/名称/@查询、四方向交易及确认菜单，使用原生 Markdown/按钮并保留文本降级。
- AzurPilot 删除旧交易终端和交易代理，只保留股票注册、绑定状态与增量上报；实例签名和上报凭据留在服务端，同步故障隔离于脚本核心业务。
- `/api/v2`、外部 PostgreSQL、受影响行事务、委托幂等与失败回滚；完整历史独立保存，交易站使用 OHLC、ETag/304 和 SSE 版本通知。历史摘要按月缓存，常规上报仅发送增量。
- 普通发行、普通小时量、融券库存、融券小时量分别可调；默认分别为 10000、1000、10000、1000。挂单整点按限价降序处理，新增阶梯税和利用率溢价后台可调，做空亏损按实际收取部分补偿发行者。
- 现实参考预设原参数保留，默认新规则单列于 `config/defaults.json`；融资、利息、交收、保证金、月赛与低行动力退市保留。交易规则在独立左侧栏目以居中表格与详细文字展示。
- Google reCAPTCHA 和旧一键部署脚本已移除。Compose 仅包含 Go 服务，不管理外部 PostgreSQL、nginx、证书或 AstrBot。

## 服务器实际结果

- 安装目录 `/opt/mingmiao-exchange`；容器 `mingmiao-exchange-exchange-1` 状态 healthy，宿主机只映射 `127.0.0.1:8888`。
- 复用已有 PostgreSQL 容器和网络，为本应用创建专用数据库及最小权限角色；原有其他数据库、容器与数据未清理或重建。专用数据库的部署前备份保存在安装目录 `backups/`。
- `.env` 的数据库密码、管理员密码、机器人 token、session secret 均随机生成长值；文件权限 600。不在交付记录或聊天中展示。管理员密码从服务器该文件读取。
- 沿用现有 nginx 与证书；仅修改本站虚拟主机：关闭继承的全局 `proxy_cache`，使条件请求传到应用；补充 IPv6 TCP 监听，避免 IPv6 命中其他站点。修改前配置已备份，`nginx -t` 成功后重载原 master。
- 源站 IPv4、源站 IPv6 与公网 IPv4/IPv6 健康接口均验证为 v2；首页、`/console`、全部页面资产校验、规则默认值、公开 ETag/304、SSE 初始版本与禁用缓冲、管理员登录/记住我/退出均通过。
- 部署镜像与运行二进制 SHA256 已核对；服务器 `DEPLOYMENT.json`、`VERIFICATION.json` 保存非敏感验收记录。
- AzurPilot 显式发送 `AzurPilot-StockExchange/2.0`，插件发送 `MingmiaoAstrBot/2.0`，规避公网对 Python 默认请求标识的拦截；真实 Python 公开规则请求已验证成功。
- 插件内部实际连接文件的 Bearer 已用真实公网 API 做只读验收，正常收到未注册身份的业务响应；未因此创建生产账户。
- 当前为 11 月 1 日，默认月赛 11 月 5 日开始，因此页面显示“本月赛事尚未开始”符合保留的月赛规则；未为验收改写生产规则或创建模拟账户/股票/委托。
