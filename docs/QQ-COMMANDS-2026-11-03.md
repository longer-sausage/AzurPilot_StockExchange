# QQ 独立帮助、指令按钮与官方面板更新

日期：2026-11-03。插件版本：v2.0.4；本机 AstrBot：v4.29.4。

## 用户可见变化

- `帮助` 显示全部用法；`帮助 注册`、`帮助 交易股票` 等显示单条说明。`菜单` 或单独 @机器人打开业务菜单。
- 主菜单八个按钮直接选择业务指令，帮助通过独立指令访问。帮助列表、返回、查询和预览确认/取消也都使用普通用户消息。
- 新按钮全部使用 [QQ 官方消息按钮协议](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/trans/msg-btn.html)的 `action.type=2`，由 QQ 客户端插入 `@机器人 + 指令`。注册、绑定股票、交易股票及裸确认/取消设置 `enter=false`，用户补全参数后发送；完整查询、帮助、菜单和带确认码的按钮设置 `enter=true`。不支持自动发送的客户端需手动发送输入框内容，尚未进行真机验收。
- 历史回调按钮不再执行业务，收到时提示生成新菜单。历史按钮原有的适配器到期字段无法追溯修改，旧提示可能仍在插件收到事件前产生。

### 无斜杠指令要求的核对

插件自身的全部按钮内容、帮助用法与示例均不加斜杠，例如 `帮助 注册`、`菜单`、`确认 <确认码>`。2026-11-03 根据用户补充要求，核对现有业务指令、帮助列表、返回与确认/取消按钮，没有为出站指令添加 `/`。

当前 QQ 官方管理页的“指令面板”存在限制：把编辑框内的 `/菜单` 改为 `菜单` 后保存草稿，列表和重新打开的编辑框仍恢复为 `/菜单`。未能通过该页面去掉平台补回的前缀，已撤销无效草稿；没有修改已保存的二十条面板指令。插件保留接收平台前缀消息的兼容解析，避免官方面板入口失效，用户手动输入及插件新按钮仍使用无斜杠形式。

本次补充运行 29 项适配器隔离测试，全部通过；另外生成主菜单、帮助列表、八个帮助页和隔离确认按钮，核对全部 27 个出站按钮及八条用法/示例均无斜杠前缀。未向真实 QQ 群发送验收消息。

本次补充只调整说明，运行代码与接口未变，现有兼容关系不受影响。必须更新：两仓说明已更新；可选更新：无；不需要更新：插件、Go 后端、交易站/管理站及 AzurPilot 前后端，无需重载、部署或重启；待确认：真实 QQ 客户端体验，官方指令面板的自动前缀仍保留。

## 实现与边界

运行代码位于独立仓库 `D:\AstrBot\data\plugins\astrbot_plugin_mingmiao_stock\`。修改 `main.py`、`stock_core.py`、`_conf_schema.json`、`metadata.yaml`、插件 README 及三份既有测试文件。本交易所仓库只新增本文并更新 README 入口，保留原有未提交文档。

AstrBot v4.29.4 的通用 `Button` 只支持回调与链接，依据为[组件源码](https://github.com/AstrBotDevs/AstrBot/blob/v4.29.4/astrbot/core/message/components.py)及[QQ 发送适配器](https://github.com/AstrBotDevs/AstrBot/blob/v4.29.4/astrbot/core/platform/sources/qqofficial/qqofficial_message_event.py)。插件复用已登录官方连接的 `bot.api.post_group_message` 和事件的 `post_c2c_message` 发送原生键盘，无新增依赖、平台凭据或核心补丁。没有可用原生发送能力时显示完整文字用法；明确展示权限拒绝才降级，不能确定是否送达时不自动补发。

所有按钮消息仍用事件下发的 `appid:openid` 和原会话；确认码绑定原发起人、原群/会话且两分钟有效。普通消息按用户实际发送的消息 ID 去重，慢导航合并、查询并发合并、确认/取消共享状态及原幂等回执恢复继续有效。注册、绑定、交易、密码与准入依旧由交易所 v2 接口处理，QQ API 只负责消息与交互展示。
