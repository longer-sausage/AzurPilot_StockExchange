## 单根 K 线显示

现场检查另发现：月初只有一根当前月份的分钟 K 线时，图表缩放使用 `filterMode: none`，预热用的旧月蜡烛会挤进当前可视区。原始报价和 API 聚合值没有错误。

`frontend/src/Charts.tsx` 将两类缩放器改为 `filter`。技术指标仍先使用完整预热数据计算，绘制时排除窗口外的数据；未改变行情查询、时间单位、月份边界或原始历史。新增浏览器回归使用隔离股票和旧月预热点，检查价格区实际绘制像素，旧实现可复现混入蜡烛，新实现仅显示当前月份的单根蜡烛。
