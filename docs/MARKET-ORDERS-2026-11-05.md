# 市价委托余量撤销修复

日期：2026-11-05（上海时区）。发布标识：`20261105-market-012024`。

## 行为与实现

市价委托只尝试当次撮合。全部成交时状态为 `filled`；部分成交或零成交时，未成交余量自动撤销，状态为 `cancelled`，保留实际成交数量、未成交数量和实际费用，释放委托冻结，不进入后续整点撮合。买入、卖出、卖空、回补均适用。

止损单未触发时仍按原有效期等待整点检查；触发后适用同样的市价余量撤销规则。触发判断提前到库存和小时额度检查之前，避免没有流动性时遗漏触发并在以后意外成交。限价单保留原有部分成交、限价边界与整点续撮规则。

启动和挂单清理会原子撤销旧版遗留的市价单、已触发止损单余量；已有成交、费用和逐笔历史保留，未触发止损与限价挂单不因此撤销。启动清理持久化失败时拒绝启动，不留下部分解冻。

实际修改：

- `internal/exchange/orders.go`：市价成交结束时撤销余量，零成交同样解冻，不再为余量预留下一次成交资金；保留工作区已有的限价部分成交修复。
- `internal/exchange/features.go`、`engine.go`：清理遗留市价余量并在启动接入请求之前提交。
- `internal/exchange/orders_market_test.go`、`postgres_test.go`：四方向、整手、零成交与部分成交、独立小时量、库存、实际税费、幂等、重启、事务失败及通知验证。
- `frontend/src/Market.tsx`、`Portfolio.tsx`、`main.tsx`、`types.ts`：市价不再选择等待有效期，预览和记录显示即时规则；主交易页与详情页按实际撤销状态显示回执，补齐已有 API 的 `triggered` 类型。
- `frontend/src/Learn.tsx`、`Rules.tsx`：同步交易说明。
- `frontend/e2e/exchange.spec.ts`：增加市价部分成交后撤销、解冻、重复确认与委托列表回归；保留已有历史测试夹具修改。
- `README.md`、`docs/API-v2.md`：同步规则与契约说明。已有 QQ 文档、交付记录和其他工作区修改保留，未提交或推送。
- `AGENTS.md`：按用户后续明确要求，将所有前端测试限定在本地，并修正部署条目中要求访问公网和源站前端的冲突规则；后端仍保留部署后的健康、API、SSE 与双栈链路验证。
